# PR figures for issue #1310

These are the existing dense/sparse figures generated by ../plot.py from the
committed ../data/*.csv.gz captures. Their baseline is
f784f7833acbd07181ea3d3bd6b0d16253b883f4; the after build applies ../fix.patch.
See ../README.md and ../provenance.json for capture details.

The vertical axes of the Before and After rows show normalized vibrato LFO
output, not audio amplitude or frequency. The CC1 row shows controller values.

The SVGs are the original vector exports. For the PNGs, those SVGs were rendered
at 7080 × 3720 using librsvg; no smoothing or data changes were applied.

The current submission branch is based on f51e95ff and has separate regression
test results; these historical figures are not described as new captures.
