# Compensated C: mathematical and real-sample screen

Date: 2026-10-16. Status: stopped before performance testing. This is an offline follow-up to the direct 2× C screen; it changes no FluidSynth production source.

## Decision

The phase-independent compensation is mathematically feasible. A finite 65-tap source-rate pre-emphasis filter brings the six-point kernel's static gain error well inside the frozen ±0.1 dB budget. The candidate still fails the real-SF2 comparison gate: active-window error versus sinc25 worsens by a median 7.28 dB and a worst case of 15.68 dB. Stop this candidate before playback benchmarks or integration.

The compensation reduced the earlier six-point median degradation from +21.12 dB to +7.28 dB, but the remaining reconstruction images and real-sample errors are still too large. This does not count as a validated optimization.

## Method

`compensated_c_math.py` uses the exact polynomial response from the archived C screen. For each frequency, it writes `|H|²` as a quartic in `u=z²`, evaluates both endpoints and every real root of the cubic derivative on `[0, 1/4]`, and obtains the minimum and maximum over interpolation phase. The source-frequency sweep uses 0.0001 spacing through 0.5, with local golden-section refinement of phase-spread peaks through the frozen 0–0.40 passband. This is a dense numerical frequency screen, not a formal interval enclosure.

The phase-independent target is `P(f)=1/sqrt(A_min(f) A_max(f))` through `f=0.40`. Above the passband it uses a cubic Hermite taper to unity at Nyquist. Symmetric source-rate FIRs are generated by truncating the target's cosine series, normalizing DC, and quantizing coefficients to float32. The 4-point variant selected 33 taps; the six-point variant selected 65 taps to keep total passband error below a 0.05 dB reserve.

The image screen analytically integrates the phase residual's Fourier coefficients `C_k`, validates them against an independent 32,768-phase midpoint quadrature at `f=0.40`, then folds orders `k=-64…64` through source steps 0.5, 0.999, 1, 1.001, 1.25, √2, 1.5, 2, and 4. Exact folded-frequency collisions are summed coherently. A 0.001 frequency grid is used over each step's legal input band. The coherent peak-sum column is a conservative sum-of-magnitudes upper bound across distinct lines; the RMS and largest single line are spectral diagnostics.

The real-sample screen applies the six-point 65-tap float32 filter at source rate before 2× table generation. The centered FIR uses finite clamping, attack-loop wrapping, and periodic-loop wrapping for their respective table representations. It then compares float and double playback against the same five-sample reference set and the existing sinc25 output. The primary rows use transpose factors 0.5 and 1.0; factor 2.0 rows remain diagnostic. No playback timing was taken.

## Reproduction and limits

For the same reference materials used here, set `FLUIDSYNTH_C_SCREEN_DATA_ROOT` to the directory containing `fractional-delay-ab/` and `cubic-sinc25/`, then run `bash run_all.sh`. The input assessment is preserved as `INPUT_ASSESSMENT.md`; original uncompensated C evidence is in [the prior C screen](../oversampled-c/REPORT.md).

This screen does not provide a continuous-frequency interval proof, complete all-order image bound, full SoundFont generalization, cold-cache or playback performance measurement, full asset loading-cost measurement, or target-device audio/xrun evidence. The real-sample gates already fail, so none of those larger tests were run. The six-point compensation remains an offline rejected candidate; no production code, optimization branch, or PR was created from it. This package is report-only.

## Error and alignment localization

A separate check used the failing `strings-mid/sustain` window at 0.5×, 882 frames, beginning 1024.27 source samples after the loop start. The window ends about 29,518 samples before the loop end and does not cross a boundary. Against the same 4095-tap reference, the compensated six-point output has −81.6725 dBFS RMS error (−69.1048 dB relative to the window RMS); sinc25 has −97.3505 dBFS (−84.7828 dB relative). Their 15.678 dB difference is 6.08× in RMS, while the absolute values show the baseline is already very accurate. The reference-convergence margin for this case is −52.34 dB, so reference truncation is far below either algorithm's error. The failure therefore persists well inside a periodic sustain window, independent of loop-entry handling.

The endpoint-to-endpoint complex-response check multiplies the actual quantized 65-tap FIR response by the six-point polynomial response and removes the ideal fractional delay. On a 0.0005-frequency by 1025-phase grid over 0–0.40 cycles/source-sample, maximum magnitude error is 0.010194 dB and maximum residual phase is 0.009554° at 0.40 cycles/source-sample. The FIR coefficients are exactly symmetric; the screen applies them centered as `sum(h[k] * x[i+k])`, so the effective fixed delay is zero. A causal implementation would have 32 source samples of linear-phase delay, but that is not how this table precomputation applies it. The even 2× slot stores filtered sample `i`, the odd slot reconstructs `i+0.5`, and playback doubles the same 32.32 phase coordinate. The 4095-tap half-phase reconstruction contributes at most 7.16e-10 output error by the recorded bound. Thus no 32-sample or half-source-sample alignment offset was found; a small position-dependent phase residual remains. Per-sample float rounding is not represented by the linear complex response, but is present in the real-SF2 measurement.

Reproduce these focused checks with `FLUIDSYNTH_C_SCREEN_DATA_ROOT=<data-root> python3 diagnose_alignment.py`; details and exact case values are in [DIAGNOSIS.md](DIAGNOSIS.md) and `alignment-diagnosis.json`. The quality gate remains failed; no threshold was changed and no performance test was run.
