# IIR steady-coefficient loop

**Decision:** rejected; the small median changes were inconsistent across inputs and the paired ranges crossed baseline.

The candidate split smoothed-coefficient updates from steady-coefficient samples. On 60-second, 64-frame Release renders with effects on, exact PCM hashes matched. For All The Small Things, three candidate/base wall ratios were 1.0110, 0.9775, and 0.9765 (median 0.9775, 2.25% faster). For POP909_010 they were 1.0265, 0.9944, and 0.9972 (median 0.9972, 0.28% faster). Each range crossed 1.0, so the source change was reverted without further testing.
