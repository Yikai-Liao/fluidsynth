### F14 — 删掉合成器后，设置变化仍会呼叫已释放的合成器

- **区域 / 类型：** 对象生命周期 / 内存安全
- **严重度：** 7 / 10
- **输入场景：** 常规合法 API 生命周期
- **影响：** 合成器注册了设置回调。删掉合成器后，回调还留在设置对象里；随后应用改一次移调时间设置，就可能访问已经释放的合成器。
- **触发条件：** 用同一个 settings 创建并销毁 synth，之后继续修改 synth.portamento-time。
- **发现方法：** 用 ASan 在删除 synth 后修改仍存活的 settings，重现回调里的 use-after-free。
- **发现时间：** 2026-10-25 约 03:14–03:16（新加坡时间）
- **生产代码改动：** `fluid_synth.c：+2 / −0 行`
- **回归测试：** `test_settings_unregister_callback`

### ✦ F01 — 路由器把不同声道的同音高音符当成一个

- **区域 / 类型：** MIDI router / 音频正确性
- **严重度：** 6 / 10
- **输入场景：** 常规合法 MIDI 输入
- **影响：** 两个输出声道同时弹同一个音高时，路由器只记了一份按键状态。清理路由规则后，第一个 NOTE OFF 会清掉第二个音符的记录，第二个关闭消息可能被丢掉，声音就挂住。
- **触发条件：** 在两个输出声道同时弹同一音高，然后清空路由规则并分别发送 NOTE OFF。
- **发现方法：** 构造双声道同音高的路由用例，基线只转发第一个 NOTE OFF。复审另发现等待清理的规则仍为未转发的新 NOTE ON / Sustain 按下登记 pending，随后可能转发幽灵关闭；现仅记录实际转发的按下事件。回归同时验证跨声道独立清理，以及被抑制的新按下不会产生关闭消息。
- **发现时间：** 2026-10-25 约 02:10（新加坡时间）
- **生产代码改动：** `fluid_midi_router.c（含按输出声道保存状态、等待规则仅追踪已转发事件）`
- **回归测试：** `test_midi_router`
- **✦ 复审更新：** 原跨声道诊断成立；补全“pending 只对应实际转发事件”的状态不变量，并纠正原测试对幽灵 NOTE OFF 的错误预期。

### ✦ F13 — 替换 SoundFont 默认调制器后，新音符会读旧地址

- **区域 / 类型：** SoundFont 生命周期 / 内存安全
- **严重度：** 6 / 10
- **输入场景：** 合法但罕见的 API 更新
- **影响：** 每个采样原先保存的是调制器链表的旧地址。应用替换 SoundFont 默认调制器后，旧链表被释放，后续新音符仍从旧地址读调制器，可能触发 use-after-free。
- **触发条件：** 加载 SF2，弹出音符；在不并发渲染的情况下替换该 SoundFont 的默认调制器，再触发新音符。
- **发现方法：** ASan 基线重现旧链表访问；回归测试覆盖有效列表替换、清空和之后的新音符。
- **发现时间：** 2026-10-25 约 03:12–03:14（新加坡时间）
- **生产代码改动：** `fluid_sfont.h / fluid_defsfont.c / fluid_dls.cpp / fluid_synth.c / fluid_sfont.c（列表间接引用及保持 NULL 清除契约）`
- **回归测试：** `test_sfont_mod_dest_bounds`
- **✦ 复审更新：** 旧列表地址的生命周期诊断和间接引用修复成立。复审撤掉附带新增的 mods!=NULL || nmods==0 限制：按原文档，mods 为 NULL 时任意非负计数都应清除列表；回归保留此兼容行为。

### F18 — 合法的 unpitched SF2 样本在自定义音律下越界

- **区域 / 类型：** SF2 播放 / 内存安全
- **严重度：** 6 / 10
- **输入场景：** 合法格式组合，但较少见

- **发现方法：** 按 SF2 规格创建 unpitched 样本并使用自定义音律；ASan 重现越界访问。修复按规格使用根音 60 回退。
- **发现时间：** 2026-10-25 约 03:35（新加坡时间）
- **生产代码改动：** `fluid_defsfont.c：+3 / −1 行`
- **回归测试：** `test_sfont_unpitched_tuning`

- **✦ 复审更新：** 文件与 API 路径的无效目标检查修到了数组下标根因。恶意 SF2 可在播放/控制器更新时导致越界读写，与调用方误用 API 的暴露面不同，排序分由 2 调为 5；同时撤掉不必要的 NULL 清除限制，保留原 API 契约。

### ✦ F30 — SF2 样本结束位置能超出 PCM 数据边界

- **区域 / 类型：** SF2 载入 / 播放 / 内存安全

- **发现时间：** 2026-10-25 约 05:20（新加坡时间）
- **生产代码改动：** `fluid_sfont.c：+1 / −1 行`
- **回归测试：** `test_sfont_sample_end_bounds`
- **✦ 复审更新：** 样本结束索引与 PCM 长度混淆的诊断成立，改为 end>=字数即拒绝修到了根因。恶意 SF2 可直接在常规播放中引起堆越界读，无需错误 API 或自定义音律，排序分由 3 调为 5。

### ✦ F02 — 合法的 8 位 DLS 样本会触发未定义行为

### ✦ F08 — 极端调音数值在 MTS 导出时转成整数会溢出

- **区域 / 类型：** MIDI Tuning Standard / 未定义行为
- **严重度：** 3 / 10
- **输入场景：** 合法 API，但极端数值少见
- **影响：** 调音 API 接收非常大的 double 或非有限数值；之后请求 MTS bulk dump 时，代码先把它转成整数，可能发生未定义行为。
- **触发条件：** 用 fluid_synth_tune_notes 设置 DBL_MAX、−DBL_MAX 或 NaN，再请求 MTS bulk tuning dump。
- **发现方法：** 公开调音 API 加 float-cast-overflow sanitizer 可重现极值转整数 UB。先在 double 域限制范围，再转换。复审把上限改为 12800−200/16384 cents，最大输出为 7F 7F 7E；避免把保留的 7F 7F 7F（不改变音高）当成最高频率。回归覆盖 DBL_MAX、负极值、12800 和临界舍入。非有限 API 输入另由 F43 拒绝。
- **发现时间：** 2026-10-25 约 02:44–02:45（新加坡时间）
- **生产代码改动：** `fluid_synth.c（转换前限幅，并排除 MTS 的 no-change 保留字）`
- **回归测试：** `test_mts_bulk_dump_pitch_range`
- **✦ 复审更新：** 原 UB 诊断成立，原补丁消除了越界转换，但其上限和测试误把 no change 当作饱和音高。现统一限制到最大有效频率字，并修正回归断言。

### ✦ F16 — DLS 的音高缩放能把 MIDI 音符变成数组外下标

- **区域 / 类型：** DLS 播放 / 内存安全
- **严重度：** 3 / 10
- **输入场景：** 构造的不合规 DLS 键号连接
- **影响：** DLS 的音高调制把按键 60 放大到 132。启用自定义音律时，内部音高表按这个值取数，越过 128 个 MIDI 音符的范围。
- **触发条件：** 在 instrument 级插入无专有条件守卫的 MIDI Note→Key 连接，将按键缩放为 2.2 倍，并启用自定义音律。
- **发现方法：** 构造可被旧加载器接受的 instrument LART，把按键 60 缩放到 132；ASan 重现 tuning 表越界。原修复只限制 melodic 分支，fresh review 又在 drum 分支加自定义 tuning 复现 132 下标。现在两个分支之后统一限制实际 key 为 0–127；回归覆盖 melodic、drum 和 drum alias 路径。DLS 2.2 §1.7.3 / Table 6 规定该隐含连接固定，普通文件不得这样重写。
- **发现时间：** 2026-10-25 约 03:22–03:24（新加坡时间）
- **生产代码改动：** `fluid_dls.cpp（melodic/drum 共用的 adjusted_key 形成点限幅）`
- **回归测试：** `test_dls_parser`
- **✦ 复审更新：** 越界成立，原“合法 DLS region 调制”输入分类已纠正，排序分由 6 调为 3。第二轮 fresh review 再发现 drum 分支漏检，现把范围约束移到分支合流后的形成点；这是对不合规连接的安全防护，不代表支持其扩展音高语义。

### ✦ F17 — 超范围固定键或根音能越过调音表

- **区域 / 类型：** SF2 播放 / 内存安全
