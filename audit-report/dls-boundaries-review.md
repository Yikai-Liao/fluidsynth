# DLS 最小边界调整复核

对比基线为本地 `upstream/master`（`c7ba7b49`）。保留上游解析函数的 offset/size 参数、字段读取语句和主体组织；不为既有函数的圈复杂度扩大重构范围。

## 接口真正替代的机制

- `read()` 统一检查当前 chunk 的剩余长度并处理 callback 失败。READ 宏、GUID、名称、PCM、PGAL 的读取不再各自解释同一种失败；保留 READ 宏作为现有字段语法的兼容入口。
- `limit(begin, size, padding)` 同时验证完整子块是否属于父块，并将 padding 排除在可读取范围之外。退出作用域自动恢复父范围，不恢复物理位置；原有遍历继续按绝对 offset 定位下一块。
- LIST、INFO 和 WVPL 共用这项范围保证。删除重复的子块长度算法、WVPL 文件长度检查，以及 fmt、RGNH、WLNK、WSMP、PGAL 中已被读取边界覆盖的判断。
- CDL 使用公共读取位置，删除手工维护的另一份字节计数。父范围验证在读取之前发生，不能先读取相邻块再报告失败。
- 文件长度及 lins/wvpl/pgal 定位数据只供加载使用，改为构造函数局部变量。新增的三个读取状态字段替代五个不需长期保留的字段；没有新增持久的文件目录模型。
- COLH、INSH、PTBL 的预分配检查继续保留：它们必须在申请内存前验证计数，逐次读取的边界不能替代这项保证。
- 两种解码路径共用 `append_sample_frames`，在 vector 增长前验证运行时字节数与样本索引的表示范围；直接写入最终 PCM 缓冲。

这些删除来自公共边界承担了完整责任。空 vector 排序、alias 初始化等外围代码保持上游形式，构造函数没有为降低 CCN 而拆分。WSMP 继续使用上游表示，没有额外 playback 模型。

## 必须保留的正确性改动

保留原始审计中的 8 位 PCM 转换、unity note 限制、gain 取负、循环端点宽算术、CDL 查询与布尔编码、条件 articulation 原子生效等修复。region 条件先于嵌套 articulation 求值；false 使用正常返回，避免留下参数。

MIDI 事件键与实际播放键仍需区分，note-off、键压力、单音转换及 voice 复用依赖此契约。相关改动只接入现有 voice 分配与转换流程，不另写一套 DLS 生命周期。

## 圈复杂度复核范围

按用户明确的规则，只复核实质新增或重写的部分。已有高 CCN 函数中的局部接口接入不触发整函数重构。

公共边界及完整新增操作的 Lizard 1.24.3 CCN：`limit` 5、`read` 6、`fseek` 6、`READCHUNK` 5、`append_sample_frames` 4、`region_applicable` 2。新增的 `fluid_dls_resolve_note_keys` 为 7，复核后保留：选择键允许不匹配任何区域，播放键必须限制在 MIDI 范围内，melodic tuning 与 drum alias 的分支共同定义这两个输出；未增加表、缓存或外部分配协议。

独立工作树：`/home/lyk/code/fluidsynth-worktrees/dls-boundaries-minimal`。其中默认调制器字段沿用上游类型，不依赖另一项默认调制器所有权修复。现有完整 DLS 回归在此工作树通过；测试未因接口改小而撤掉缺陷覆盖。

范围检查仅用于加载期，不增加 PCM 副本或堆分配次数。缓存物理位置避免对同一位置重复 seek；保留上游的波形解码循环。未进行吞吐基准测量。
